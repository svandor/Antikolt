# Forrás: a kiinduló terv

Ebben a mappában a projekt **kiinduló terve** található, változatlan formában, hogy később visszakereshető
legyen, miből indult a tervezés.

| Fájl | Mi ez |
|---|---|
| `gemini-terv-v1.odt` | Az eredeti dokumentum (LibreOffice/ODT), ahogy készült |
| `gemini-terv-v1.txt` | Szövegkivonat az ODT `content.xml`-jéből, olvasáshoz és kereséshez |
| `kutatas/cef-webauthn-2026.md` | Kutatási jegyzet: CEF és WebAuthn/passkey támogatás (forrásokkal) |
| `kutatas/kodalairas-2026.md` | Kutatási jegyzet: kódaláírás, SmartScreen, tanúsítványárak (forrásokkal) |
| `kutatas/licenc-2026.md` | Kutatási jegyzet: licenc, Qt LGPL, CEF BSD, DCO, AI-szerzőség (forrásokkal) |

A `kutatas/` mappa nyers kutatási anyag: a benne lévő állítások a `../HU/12-PASSKEY.md`,
`../HU/13-LICENC.md` és `../HU/14-KODALAS.md` dokumentumokban kerültek feldolgozásra, ott a mérvadó
következtetés.

**Eredet:** a projektgazda által készített és átadott terv (Gemini segítségével), 2026. november.
**SHA-256 (odt):** `5775976364617a33e8c8a1c558ce3ba1de0054d71510ab7d33a82ef56065a7b8`

**Fontos:** ez a dokumentum **történeti forrás**, nem mérvadó. A mérvadó terv a [`../HU/`](../HU/) mappában
van. A szövegkivonat formázás nélküli (a címsorok, félkövér kiemelések elvesztek), ezért hivatkozáskor
mindig az ODT az irányadó.

A bírálat, amely megmondja, mi maradt meg ebből a tervből és mi változott:
[`../HU/00-JAVASLATOK.md`](../HU/00-JAVASLATOK.md).
